## 기능 구현 목록

### 입력

- [ ] 문자열을 입력받는다
    - `Console.readLine()` 사용

### 기본 구분자 처리

- [ ] 쉼표(,)를 구분자로 사용한다
- [ ] 콜론(:)을 구분자로 사용한다
- [ ] 쉼표와 콜론을 함께 사용할 수 있다
- [ ] 구분자로 분리된 숫자들의 합을 계산한다

#### 테스트 케이스

- [ ] 빈 문자열("")은 0을 반환한다
- [ ] "1,2"는 3을 반환한다
- [ ] "1,2,3"은 6을 반환한다
- [ ] "1,2:3"은 6을 반환한다

### 커스텀 구분자 처리

- [ ] "//"와 "\n" 사이의 문자를 커스텀 구분자로 사용한다
- [ ] 커스텀 구분자로 숫자를 분리하여 합을 계산한다

#### 테스트 케이스

- [ ] "//;\n1;2;3"은 6을 반환한다

### 출력

- [ ] 계산 결과를 "결과 : {숫자}" 형식으로 출력한다

### 예외 처리

- [ ] 잘못된 값 입력 시 `IllegalArgumentException` 발생
- [ ] 애플리케이션 종료

## 도메인 후보

### 1. Numbers (숫자들)

**책임:**

- 숫자 배열 관리
- 합 계산
- 숫자 검증 (음수 등)

### 2. Delimiter (구분자)

**책임:**

- 기본 구분자 (쉼표, 콜론)
- 커스텀 구분자 파싱
- 문자열 분리

### 3. StringCalculator (계산기)

**책임:**

- 전체 흐름 조율
- Delimiter와 Numbers 사용
